# SecureLMS Enterprise 🚀

## 📌 Project Overview

SecureLMS Enterprise is a simple client-side web application developed using HTML, CSS, and JavaScript.
It provides features like user login, course browsing, enrollment, and a dashboard.

The application is deployed on Microsoft Azure and is accessible over the internet.

---

## 🔐 Security Features

* Input validation for login fields
* XSS protection using sanitization and escaping
* Basic authentication system
* Secure session handling using local storage
* HTTPS encryption provided by Azure

---

## 🚀 Deployment

The application is deployed using Microsoft Azure Static Web Apps.

Steps:

1. Created GitHub repository
2. Uploaded project files
3. Connected GitHub to Azure
4. Deployed using Azure Static Web Apps
5. Application is live via public URL
